BACKEND CHANGES:

1. Update POST /api/subcontratos/reporte to 
   accept an array of activities:
   {
     proyecto_id: uuid,
     fecha: date,
     tecnicos_presentes: [],
     cantidad_tecnicos: number,
     actividades: [
       {
         actividad_id: uuid,

       }
     ],
     descripcion_trabajo: text,
     fotos: [],
     hora_checkin: text,
     hora_checkout: text

     WHERE id = actividad_id

     SET completada = true
