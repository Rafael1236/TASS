Please update the subcontracts project lifecycle 
to handle all states based on dates correctly.

PROJECT LIFECYCLE STATES:
Calculate state dynamically based on dates:

1. "por_iniciar" — fecha_inicio is in the future
   TODAY < fecha_inicio

2. "en_progreso" — project is active
   fecha_inicio <= TODAY <= fecha_fin_estimada

3. "en_riesgo" — over 80% of days consumed
   dias_transcurridos >= (dias_maximos * 0.8)
   AND TODAY <= fecha_fin_estimada

4. "vencido" — past end date, not completed
   TODAY > fecha_fin_estimada AND 
   estado != 'completado'

5. "completado" — manually marked as done

DAYS CALCULATION:
Always calculate dynamically, never store:

IF state is "por_iniciar":
  dias_para_iniciar = fecha_inicio - TODAY
  
IF state is "en_progreso" or "en_riesgo":
  dias_transcurridos = TODAY - fecha_inicio
  dias_restantes = fecha_fin_estimada - TODAY
  porcentaje_dias = (dias_transcurridos / 
    dias_maximos) * 100

IF state is "vencido":
  dias_vencido = TODAY - fecha_fin_estimada
