Replace the current separate search inputs

DESIGN:

- Clear button (×) on the right when

AUTO-DETECT LOGIC:
The search should automatically detect 
what the user is typing:

1. If input is a NUMBER only (digits):
   - Search BOTH numero_llamada AND 
     numero_reporte simultaneously
   - Show results grouped:
     "# Llamada: X resultados"
     "# Boleta: X resultados"

2. If input contains LETTERS:
   - Search cliente_nombre 
     using ILIKE '%term%'
   - Show matching clients in dropdown
   - When client selected: show their 
     call numbers as a second step
   - User selects call number → 
     shows full consolidated report

3. If user selects [# Llamada] pill first:
   - Only search numero_llamada
   - Show full consolidated report directly

4. If user selects [# Boleta] pill first:
   - Only search numero_reporte
   - Show that specific boleta detail

5. If user selects [👤 Cliente] pill first:
   - Only search cliente_nombre
   - Show client dropdown → 
     call numbers → full report
